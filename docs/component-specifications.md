# Component specifications

## Navigation

Desktop navigation is a 232px sidebar that can collapse to a 78px icon rail. At 900px and below it becomes a four-item bottom bar with safe-area padding. Every item has an SVG icon, visible mobile label, tooltip, and accessible name.

## Buttons

Primary and secondary buttons share a minimum 44px height. Primary actions are reserved for the main task. Destructive actions use the negative semantic color and are separated from routine actions.

## Fields

Fields use a persistent label, 6px label-to-control gap, 44px minimum control height, and a nearby helper or conversion preview. Currency and amount are grouped as one control.

## Sheets

Sheets are up to 560px wide, capped at 92vh/760px, internally scrollable, safe-area padded, dismissible by Close, scrim, or Escape, and preserve entered values when saving fails.

## Lists

Financial rows use a shared 68px minimum anatomy: title, concise metadata, right-aligned tabular amount, and an optional contextual action.
