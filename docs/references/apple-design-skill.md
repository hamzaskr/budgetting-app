# Apple Design Skill Reference

This project follows the supplied interaction requirements: immediate press feedback, progressive disclosure, interruptible motion, pointer-aware sheets, semantic materials, native typography, safe touch targets, and independent reduced-motion, reduced-transparency, and increased-contrast adaptations.

The implementation keeps the common financial path short: add a source, record an expense, income, or transfer, and inspect current balances. Optional categories and notes remain optional. All financial data remains local to the browser.
